# Site security review — 2026-09-20

Reviewed the site release based on `609dda7`, including Worker routes, model calls, session storage, browser assets, and optional PostHog capture. Claude Fable 5.1 reviewed the source independently; its final source-only verdict was “no new shipping blockers or regressions” and “Ship with analytics disabled.” This is a source and behavior review, not a penetration test or an audit of Cloudflare account permissions.

1. **Credentials and isolation.** Gateway credentials stay in Worker bindings. Gitleaks found no secrets in the working tree, generated assets, or scanned Git history. The `__Host-waymode_session` cookie is HttpOnly, Secure, SameSite=Strict, host-only, and valid for one hour. A derived trace label cannot act as that cookie. Tests cover visitor state, action ownership, trace isolation, and old-cookie rejection. Same-origin checks reject cross-site session creation and foreign mutations. These checks do not authenticate bots.

2. **Abuse and cost bounds.** The Worker rejects large bodies and cancels stalled reads after ten seconds. Cloudflare edge rate limits run before shared storage; persistent Durable Object quotas remain authoritative. IPv6 addresses share a /64 bucket. Stored network identifiers use HMAC with a random daily secret. Expiry checks, periodic pruning, trace retention limits, stream caps, and slow-reader cancellation bound storage and memory. At most four model calls run together. Model limits are 12/network/minute, 60/site/minute, 150/site/hour, 100/network/day, and 60/session. The shared daily cap is temporarily 1,200 until September 23, 2026 at 00:00 UTC, then 600. Preview model calls remain disabled. Calls, including failed attempts, consume reservations; these limits are not a dollar budget. Distributed visitors can still exhaust the shared pool. Edge counters are eventually consistent, as described in [Cloudflare's documentation](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/).

3. **Browser and telemetry boundaries.** Script CSP no longer permits inline executable scripts or Cloudflare's analytics beacon. Google Fonts remains an external font request and is disclosed in the privacy page. SQL uses bound parameters and runtime text uses text nodes. API logs retain route, status, timing, and generated request IDs; model logs retain usage and errors without prompt bodies, raw IPs, or auth cookies. Invocation logging is disabled. Request scopes separate concurrent model logs. No uptime alerts, log export, or provider dollar budget is configured in this change.

4. **Analytics stays disabled.** PostHog is pinned to `1.434.2`; its options compile against that version's types. The SDK loads only with a valid public project key and visitor opt-in. GPC and Do Not Track override prior consent. Autocapture handles clicks, heatmaps, and navigation; replay may retain drafts in marked prompt fields. One runtime bridge records submitted and suggested prompts, decisions, outcomes, and stop requests. Other inputs, network bodies, auth headers, cookies, and raw trace panels are excluded from replay. Credential fields and common secret patterns are redacted; arbitrary confidential text cannot be reliably detected. URL queries and fragments are removed while event timestamps retain their Date type. Cookies are scoped to the current host. Withdrawal stops future capture but does not delete prior records. No real project has been supplied: retention, team access, ingestion, both embedded frames, and consent withdrawal must be verified in that project before collection starts. Browser blockers and bounded payloads prevent any promise of complete capture.

5. **Evidence and limits.** `npm run verify` passed 132 tests across 33 files, lint, type checks, formatting, production builds, and release checks. `npm audit` reported zero known vulnerabilities. Tests cover stalled/oversized bodies, quotas across restarts, stream bounds, daily network-key rotation, edge rejection before storage, consent, secret masking, and request correlation. Local Worker checks confirmed cross-site rejection, the hardened cookie, and disabled analytics. A measured burst within one minute returned 240 successes followed by ten 429 responses from the native edge binding. Browser checks confirmed the renamed product API, settings-only view, and copy feedback. The embedded test browser also reported an unattributed MutationObserver error that page error listeners did not capture; no app failure was observed, but a second-browser check remains useful. Real PostHog ingestion and a new live model completion are not claimed by these local checks.
